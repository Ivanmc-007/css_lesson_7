# Практическая работа №6: Современные веб-формы и адаптивная верстка

Добро пожаловать в репозиторий практической работы курса «Интернет-технологии» (ИПК БГУ). В рамках этого задания вам предстоит выполнить рефакторинг и стилизацию современной веб-формы, превратив «сырую» заготовку в качественный продакшен-интерфейс.

## 📋 Техническое задание

Ваша задача — взять за основу исходный код файла `zadanie-1.html` и доработать его в соответствии с тремя скриншотами-эталонами, находящимися в папке `images/` (`layout-desktop.png`, `layout-tablet.png`, `layout-mobile.png`).

### Требования к выполнению работы:

1. **Семантика HTML5:** Рефакторинг структуры формы с использованием `fieldset`, `legend`, а также жесткой связи `label` и полей ввода через `for` и `id`.
2. **Типы и валидация:** Применение корректных типов полей (`email`, `tel`), атрибутов `required` и `placeholder`.
3. **Контроль в CSS:** Запрет на использование общих сокращений (например, `background`) вместо конкретных свойств.
4. **Адаптивность:** Настройка сетки на базе Flexbox или CSS Grid для адаптивности под любые экраны без горизонтального скролла.

## 🚀 Инструкция по сдаче работы (GitHub Workflow)

1. Выполните **Fork** репозитория.
2. Склонируйте его на локальный компьютер.
3. Создайте ветку `homework-06`.
4. Создайте персональную папку по шаблону: `Фамилия_Имя_Группа`.
5. Перенесите туда заготовку файла.
6. Сделайте **не менее 3 коммитов** в процессе работы.
7. Отправьте изменения в свой форк.
8. Откройте **Pull Request** в ветку `main` исходного репозитория.
